# RecipeCook.TelegramBot

**RecipeCook.TelegramBot** — это Telegram-бот, который содержит тысячи различных рецептов. Всё, что нужно сделать пользователю — просто написать название блюда, и бот найдёт подходящий рецепт. Проект создан с использованием C# Telegram Bot API и Spoonacular API.

> **Важное примечание:** на данный момент бот не работает, поскольку он не задеплоен на постоянном хостинге. Вы можете самостоятельно запустить его на собственном компьютере с помощью консольного приложения.

## О проекте

Бот создан с целью ознакомления с [C# Telegram Bot API](https://github.com/TelegramBots/Telegram.Bot). Его основная задача — поиск рецепта блюда по его названию, а также предложение случайного рецепта. База данных с рецептами предоставляется [Spoonacular API](https://spoonacular.com/food-api).

**Ссылка на бота в Telegram:** [@RecipeCook_bot](https://t.me/RecipeCook_bot)

---

## Возможности

- 🔍 **Поиск рецепта по названию** — отправьте боту название любого блюда, и он найдёт подходящий рецепт.
- 🎲 **Случайный рецепт** — команда `/random` предложит случайное блюдо из базы.
- ℹ️ **Информация о боте** — команда `/getinfo` выдаёт сведения о боте и ссылки на использованные API.
- 🥚 **Пасхалка** — команда `/easteregg` для любителей секретов.

---

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запускает работу бота |
| `/stop` | Отключает бота в любой момент |
| Любое название блюда | Производит поиск блюда по названию |
| `/random` | Выдаёт случайный рецепт |
| `/getinfo` | Выдаёт информацию о боте и ссылки на API |
| `/easteregg` | Пасхалка |

## Требования

Для запуска проекта вам потребуется:

- **Visual Studio** (или любая другая IDE с поддержкой .NET)
- **.NET SDK** (версия, совместимая с проектом `Console_TelegramBot.csproj`)

- **API-ключ Spoonacular** — зарегистрируйтесь на [spoonacular.com](https://spoonacular.com/food-api) и получите ключ

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Aakiyaru/RecipeCook.TelegramBot.git
cd RecipeCook.TelegramBot
```

### 2. Настройка токена и API-ключа

В проекте используется токен бота и ключ Spoonacular API. **Не публикуйте их в открытых репозиториях.** Рекомендуется хранить секреты в переменных окружения или в отдельном файле конфигурации, который добавлен в `.gitignore`.

### 3. Запуск через Visual Studio

1. Откройте файл `Console_TelegramBot.sln` в Visual Studio.
2. Убедитесь, что все зависимости установлены.
3. Нажмите **F5** для сборки и запуска проекта.

### 4. Запуск через публикацию в папку

1. Опубликуйте проект в локальную папку (например, через `dotnet publish`).
2. Запустите полученный `.exe`-файл.

После запуска консоль выведет версию бота и его токен. Для начала работы бота напишите `/start`, для отключения — `/stop`. Если пользователь отправит сообщение боту, в консоль выведется информация о пользователе, его сообщение, а также логи выполнения команды.

## Использование

1. Запустите бота любым из способов, описанных выше.
2. Откройте Telegram и найдите бота по ссылке [@RecipeCook_bot](https://t.me/RecipeCook_bot) или по имени, которое вы задали через @BotFather.
3. Отправьте команду `/start`.
4. Напишите название любого блюда, например: `паста карбонара`.
5. Бот отправит вам рецепт с описанием, ингредиентами и инструкцией по приготовлению.
6. Используйте `/random` для получения случайного рецепта.
7. Для завершения работы отправьте `/stop`.
